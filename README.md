# Web Projects

Full-stack web apps by **Jamar (Jah) Brown**, built with Node.js and Express, PostgreSQL, and React. Each folder is its own app with its own README and setup steps.

| Project | What it does | Stack |
| --- | --- | --- |
| [On the Fly](onthefly/) | A group trip planner: create trips with dates and a budget, add destinations, suggest and upvote activities, and see who's coming. Members sign in with GitHub. | React, Express, PostgreSQL, GitHub OAuth |
| [Video Game Store](video_gameStore/) | A game customizer: pick a genre, setting, platform, cover image and color, watch the price and preview update, then save, edit, or delete your games. Rules stop impossible combinations. Prices are made up and nothing is for sale. | React, Express, PostgreSQL |
| [Xenoblade Locations](xenoblade1_Locations/) | A community space for five Xenoblade Chronicles locations, each with its own page of events, live countdowns, and a filter by location. | React, Express, PostgreSQL |
| [Dark Souls II Weapons, with database](./dark-souls2-weapons:database/) | A weapon archive with detail pages and case-insensitive search by name, with the weapons stored in PostgreSQL. | HTML, CSS, JavaScript, Express, PostgreSQL |
| [Dark Souls II Weapons](dark-souls2-weapons/) | The first version of the weapon archive: seven weapons with detail pages, served by Express. | HTML, CSS, JavaScript, Express |

My main portfolio project is [REV, The Ruby Enigma Vault](https://github.com/JamarBrown3/rev-ruby-enigma-vault): a gaming community and business dashboard built with React, Express, and MongoDB.
